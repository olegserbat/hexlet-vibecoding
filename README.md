# Приём у Апюса

Шуточный тестовый проект: лендинг с онлайн-записью на приём.

**Сайт:** https://olegserbat.github.io/hexlet-vibecoding/

## Как устроено

- `index.html` — вся страница целиком: вёрстка, стили, тексты. Ни сборки, ни зависимостей.
- Форма записи — [Яндекс Формы](https://forms.yandex.ru/u/6a831f72e010dbfa888fa2eb/), встроена через iframe с официальным скриптом авторазмера.
- Заявки — [таблица «Запись на прием (тест).xlsx»](https://disk.yandex.ru/i/HGAuuZE0uKM59w) на Яндекс Диске.
- Публикация — GitHub Pages из ветки `main`, корень репозитория.

## Куда попадают заявки

Ответы всегда сохраняются в самой Яндекс Форме — раздел «Ответы», оттуда же выгружаются в XLSX.

Автоматическая выгрузка в таблицу на Диске настраивается **в настройках формы** (раздел интеграций),
а не в коде лендинга: статическая страница на GitHub Pages не может писать в файл на Яндекс Диске —
для этого нужен серверный обработчик с токеном доступа, а токен в публичном репозитории размещать нельзя.

## Локальный запуск

Отдельного сервера не нужно — достаточно открыть файл в браузере:

```
open index.html
```
